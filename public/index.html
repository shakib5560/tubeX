API Documentation

Base URL: https://api.example.com

Users

GET /api/v1.0/users

Fetch all registered users.

Status 200 OK 
{
  "success": true,
  "data": [
    {
      "id": "64f5e2a1b3f9c9d1a0a1b2c3",
      "name": "Shakib",
      "email": "shakib@example.com"
    }
  ]
}

Authentication

POST /api/v1.0/auth/register

Register a new user. Supports optional avatar and cover image uploads.

Status 201 Created 
{
  "success": true,
  "user": {
    "id": "64f5e2a1b3f9c9d1a0a1b2c3",
    "username": "shakib",
    "email": "shakib@example.com",
    "avatar": "https://res.cloudinary.com/.../avatar.webp",
    "coverImage": "https://res.cloudinary.com/.../cover.webp"
  },
  "tokens": {
    "accessToken": "jwt_access_token_here",
    "refreshToken": "jwt_refresh_token_here"
  }
}
POST /api/v1.0/auth/login

Authenticate user and return access & refresh tokens.

Status 200 OK 
{
  "success": true,
  "tokens": {
    "accessToken": "jwt_access_token_here",
    "refreshToken": "jwt_refresh_token_here"
  }
}
POST /api/v1.0/auth/logout

Logs out the authenticated user and invalidates the refresh token.

Status 200 OK 
{
  "success": true,
  "message": "User logged out successfully"
}
POST /api/v1.0/auth/refresh-token

Generate a new access token using a valid refresh token.

Status 200 OK 
{
  "success": true,
  "accessToken": "new_jwt_access_token_here"
}
