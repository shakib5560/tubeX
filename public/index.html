API Documentation

Base URL: https://api.example.com

Users

GET /api/v1.0/users

Fetch all registered users.

Status 200 OK

Response

{
  "success": true,
  "data": [
    {
      "id": 1,
      "name": "Shakib",
      "email": "shakib@example.com"
    }
  ]
}

Register

POST /api/v1.0/auth/register

Authenticate user create register.

Status 200 OK 
{
  "success": true,
  "username": "shakib",
  "email": "user@email.com"
  "password": "password"
}

Login

POST /api/v1.0/auth/login

Authenticate user and return access token.

Status 200 OK 
{
  "success": true,
  "token": "jwt_access_token_here"
}

Blog

GET /api/v1.0/blogs

Retrieve all published blog posts.

Status 200 OK
